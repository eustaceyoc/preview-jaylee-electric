# Jaylee Electric (sample site)

A sample website I designed for Jaylee Electric, an electrical contractor in Fort Worth, TX. I put together sites like this to show local businesses what a modern, mobile-friendly web presence could look like for them before they commit to anything.

**Live preview:** https://preview-jaylee-electric.vercel.app

## Design

Dark charcoal with electric-yellow accents, a bold grotesque headline face (Bricolage Grotesque), and a credentials section up front, since licensing and insurance are what people check first when hiring an electrician.

## Stack

- Plain HTML and CSS in a single `index.html`, with no framework and no build step
- Responsive, mobile-first layout
- Google Fonts, plus photos from Unsplash (credited on the page)
- Hosted on Vercel

## Running it locally

Open `index.html` in a browser, or serve the folder with something like `npx serve .`

## Notes

- This is a sample site, not the business's official website, and it isn't affiliated with or published by Jaylee Electric.
- The contact form is for demo purposes only and doesn't send anything.
- Search engines are blocked for now (`robots.txt` and a `noindex` header in `vercel.json`) until the business decides whether it wants the site live.
